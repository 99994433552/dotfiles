# humanizer-ua

Skill для Claude Code, що знаходить і прибирає ознаки ШІ-тексту з українських текстів.

Англійський [blader/humanizer](https://github.com/blader/humanizer) добре працює з англійською, але з українською промахується: інша морфологія, інша стилістика, русизми замість AI vocabulary, частки замість discourse markers. Цей skill написаний спеціально для української мови.

## Встановлення

### Рекомендовано (клонувати в директорію skills)

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/yevhenii-nepsha/humanizer-ua.git ~/.agents/skills/humanizer-ua
```

### Вручну (тільки файл skill)

```bash
mkdir -p ~/.agents/skills/humanizer-ua
cp SKILL.md ~/.agents/skills/humanizer-ua/
```

## Використання

В Claude Code skill викликається автоматично при роботі з українським текстом, або вручну:

```
Гуманізуй цей текст: [ваш текст]
```

## Що він робить

Шукає 27 патернів у 7 категоріях. Кожен з прикладами До/Після. Перед початком визначає тип тексту (блог, документація, короткий текст) і відповідно дозує патерни.

### Морфологія (суто українське, в англійському skill цього немає)

| # | Патерн | ШІ пише | Треба |
|---|--------|---------|-------|
| 1 | Кличний відмінок | *Олександр, підійди* | *Олександре, підійди* |
| 2 | Родовий -а/-у | *питання прогреса* | *питання прогресу* |
| 3 | Давальний -ові/-еві | *Передай Петру* | *Передай Петрові* |
| 4 | Вид дієслова | *буду зробити* | *зроблю* |
| 5 | Дієприслівники -ючи/-ачи | *залучаючи інвестиції, створюючи...* | Окремі речення |

## Приклад

### До:

> У сучасному світі штучний інтелект відіграє ключову роль у розвитку програмного забезпечення, являючись невід'ємною частиною сучасного технологічного ландшафту. Варто зазначити, що ключова перевага полягає у трьох аспектах: прискоренні розробки, підвищенні якості та зниженні витрат. На протязі слідуючих років ця технологія буде приймати все більшу участь у вирішенні проблем розробки.

### Після:

> ШІ-асистенти можуть прискорити нудну частину роботи. Не всю роботу. Точно не архітектуру. З бойлерплейтом вони справляються: конфіги, тестові заготовки, рутинний рефакторинг. А ще вони вміють звучати переконливо, коли насправді несуть дурню. Я от сам приймав підказки, які і компілювалися, і лінтер проходили — а потім виявлялося, що вони взагалі не про те.

## Чим відрізняється від англійського humanizer

| Аспект | [blader/humanizer](https://github.com/blader/humanizer) | humanizer-ua |
|--------|--------------------------------------------------------|--------------|
| Мова | Англійська | Українська |
| Морфологія | Немає (англійська не має відмінків) | Кличний, родовий -а/-у, давальний -ові/-еві, вид дієслова |
| Лексика | AI vocabulary (delve, foster, tapestry) | Слова-маркери + русизми-кальки (21 заміна) + канцелярит |
| Синтаксис | -ing constructions, copula avoidance | Частки (ж/бо/от), дієприслівники -ючи/-ачи, дії неживих об'єктів |
| Пунктуація | Em dashes, curly quotes | Тире замість «є», лапки « » |
| Стиль | Rule of three, Title Case | Те саме + пафосність, перелічувальність |
| Структура | Немає | Фальшива універсальність, абстрактний вступ, запізніла ідентифікація автора |
