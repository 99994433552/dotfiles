# External Knowledge & Research

Verify information about libraries, APIs, and third-party code when uncertain.

## When to Verify

- Library versions, API endpoints, or syntax may have changed
- Newer libraries released after training cutoff
- User mentions specific version numbers
- Best practices may have evolved

## How to Verify

- Use WebFetch for current standards and best practices
- Check official documentation for latest API signatures
- Confirm breaking changes or deprecations

## Principles

- Treat training data as potentially outdated
- Verify before providing code patterns
- Research when uncertain about version compatibility
